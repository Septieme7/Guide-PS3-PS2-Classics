Complete Guide: Install Your PS2 Classics on PS3 CFW/HEN

This tutorial guides you step-by-step through installing PS2 Classics on a modified PlayStation 3 (CFW or HEN). Whether you use a USB drive or FTP, every method is detailed with exact commands and paths to follow.

ℹ️

Important: This guide applies to PS3 consoles running CFW (Custom Firmware) and HEN (Homebrew Enabler).
CFW offers a simpler method (unencrypted ISO in PS2ISO), while HEN requires conversion to PKG.

🔄

Update: This guide includes methods for official PS2 Classics games and mods (like the Dragon Ball Z versions). Download links for the mods are provided in the dedicated section.

02

Essential Prerequisites

Before you start, make sure you have:

  • A modified PS3: CFW (Evilnat, Rebug, etc.) or PS3HEN enabled.
  • A .pkg file of a PS2 Classics game (or a PS2 ISO to convert).
  • A USB drive formatted in FAT32 (or NTFS for large files > 4 GB).
  • A PC with PS2 Classics GUI (if you convert your own ISOs).
  • The PS2 Classics Placeholder installed (for HEN).
⚠️

HEN Reminder: On PS3HEN, you must enable HEN before each session. Without it, PS2 Classics games will not launch.

03

Method 1: Installation via USB Drive (Simple)

This is the most direct method. It involves placing the .pkg file on a USB drive, then installing it from the XMB.

Step 1: Prepare the USB Drive

  1. Format your USB drive in FAT32 (or NTFS if the .pkg file exceeds 4 GB).
  2. At the root of the drive, create a folder named PKG (in uppercase).
  3. Copy the .pkg file into this PKG folder.

Step 2: Install from the PS3

  1. Insert the USB drive into a PS3 port.
  2. On the XMB, go to Game > Package Manager > Install Package Files.
  3. Select USB Storage Device (or the name of your drive).
  4. Navigate to the PKG folder and select the .pkg file.
  5. Press X to install.
  6. Once installation is complete, the game appears in the Game column of the XMB.
💡

Tip: For very large files, use an NTFS drive. FAT32 is limited to 4 GB per file.

04

Method 2: Installation via FTP (Advanced)

Ideal for large files or if you don't want to use a USB drive. You transfer the PKG directly to the PS3's hard drive.

Step 1: Configure the FTP Server on PS3

  1. Make sure webMAN MOD or multiMAN is running (it enables the FTP server).
  2. Note your PS3's IP address (visible in Settings > Network Settings > Connection Status).

Step 2: Transfer the File with FileZilla

  1. Open FileZilla on your PC.
  2. In the top fields, enter:
    • Host: 192.168.1.70 (your PS3's IP)
    • Username: root
    • Password: (blank by default)
    • Port: 21
  3. Click Quickconnect.
  4. In the right pane (PS3), navigate to /dev_hdd0/packages/.
  5. In the left pane (your PC), locate your .pkg file.
  6. Drag and drop the file into the packages folder.
  7. Wait for the transfer to finish.
⚠️

Important: Make sure the transfer mode is set to Binary (menu Transfer > Transfer Type > Binary). An ASCII transfer will corrupt the file.

Step 3: Install from the XMB

  1. On the PS3, go to Game > Package Manager > Install Package Files.
  2. Select System Storage (the internal hard drive).
  3. The .pkg file appears in the list. Select it and press X.
  4. Confirm the installation and wait for it to finish.
05

Launch via webMAN MOD (Recommended)

webMAN MOD is the ideal tool for managing and launching your PS2 Classics. It provides quick access to the game library and allows mounting ISOs.

Install webMAN MOD

  1. Download the latest webMAN_MOD_[version]_Installer.pkg from the GitHub releases page.
  2. Install it via the USB or FTP method explained above.
  3. After installation, launch the webMAN MOD icon from the XMB.

Launch a PS2 Classics Game

  1. Open webMAN MOD (via XMB or the web interface).
  2. Navigate to the Games > PlayStation 2 section (or PS2 Classics).
  3. Select your game from the list. webMAN will mount it automatically.
  4. The game will launch like a normal PS3 game.
ℹ️

Web Access: You can also manage your PS3 from a PC browser by typing http://[PS3-IP]/.

Dragon Ball Z Mods (Budokai Tenkaichi 3)

The Dragon Ball Z: Budokai Tenkaichi 3 mods are modified versions of the PS2 game, converted to PKG for PS3. They add new characters, transformations, and adjust gameplay.

  3. The mod will appear in the XMB under its name (e.g., "CANON v4" or "SUPER MAX v7").

klicensee Licenses — Understanding and Obtaining Keys

PS2 Classics games are not simple ISOs: they are encrypted PKGs that require a digital license key called klicensee to be unlocked. Without this key, the PS3 will refuse to launch the game.

🔑 What is klicensee?

The klicensee is a unique license key that allows decrypting the content of a PS2 Classics game. Two very different cases must be distinguished:

Game TypeSourceklicensee
Official PSN Games Purchased on the PlayStation Store (or obtained via NoPayStation) Unique per game — stored in the ISO.BIN.EDAT file inside the PKG
Community-created games Converted by yourself (PS2 Classics GUI) or by modders Generic and universal for all games (see below)
🔑

Universal generic key (for community-created games):

E4E54FD67C16C316F47829A30484D843

This key is used by default in PS2 Classics GUI and by most mods. It works on all CFW/HEN PS3 consoles.

ℹ️

Structure of an official PS2 Classics PKG:

  • ISO.BIN.EDAT — the PS2 game ISO encrypted with the klicensee.
  • PARAM.SFO — metadata (title, ID, category).
  • ICON0.PNG — the game icon in the XMB.
  • The Placeholder (separate): [PS2U10000]_PS2_Classics_Placeholder.pkg.

The klicensee is used to decrypt the ISO.BIN.EDAT at launch time. This is why each official game has its own key.

📥 Where to find official PS2 Classics games?

Official PS2 Classics games are distributed as encrypted PKGs. Here are the most reliable community-used sources:

SourceDescriptionLink

DLPSGame (PS2) Site offering PS2 game downloads in ISO format. The ISOs can then be converted to PKG with PS2 Classics GUI. dlpsgame.com/category/ps2

🛠️ How to obtain the klicensee of an official game?

Three main methods exist, depending on what you have:

Method 1: Extraction from the PKG with PS2 Classics GUI

This is the simplest method if you already have the official PKG.

  1. Download and launch PS2 Classics GUI on your PC.
  2. Open the "Decrypt" tab.
  3. Select your official .pkg file.
  4. Enter the klicensee (if you already have it) or click "Get klicensee from RAP" if you have the associated .rap file.
  5. Start the decryption: the software extracts the decrypted PS2 ISO to the folder of your choice.

Method 2: Extraction from a RAP file

If you have the .rap (Sony license file) but not the klicensee, use a converter.

  1. Get the .rap file corresponding to the game (provided with the PKG on NoPayStation).
  2. Download the rap2klicensee.exe tool (available on PSX-Place or in the Aldostools toolbox).
  3. Place the .rap in the same folder as the tool.
  4. Run the command: 
    rap2klicensee.exe my_game.rap
  5. The tool displays the corresponding klicensee (32 hexadecimal characters).

Method 3: Community klicensee database

The community maintains public klicensee lists for the most common PS2 Classics games.

  • PSX-Place: "PS3 PS2 Classics" section of the forum — many topics share klicensee lists.
  • GitHub: search for ps2-classics-klicensee or klicensee-database — several repositories maintain .txt files with the keys.
  • PS3 Scene Discord: servers like "PS3 Homebrew" or "PS3 Scene" have dedicated channels where keys circulate.
⚠️

Important: The klicensee is specific to each official game. Never reuse a klicensee from another game — the PS3 would refuse to launch the PKG.

PKGi Store — Download PKGs Directly on PS3

PKGi PS3 is a homebrew that allows you to download and install .pkg files directly on your PS3, without using a PC. It is the ideal tool to retrieve PS2 Classics games from community repositories like NoPayStation or custom configurations.

ℹ️

PKGi only handles .pkg files. It does not download raw PS2 ISOs. For those, use webMAN MOD (ISO in /dev_hdd0/PS2ISO/) or convert them with PS2 Classics GUI.

Installing PKGi

  1. Download the latest pkgi-ps3.pkg from the GitHub releases page.
  2. Install it via the USB or FTP method explained above.
  3. Launch the PKGi icon from the XMB (Network column).

Configuring PKGi with NoPayStation

To download games from NoPayStation, you need to provide PKGi with a pkgi.txt file containing the game list.

  1. Get the pkgi.txt file provided by NoPayStation (or download HERE : https://github.com/Septieme7/PS3-PKGI-1.30 with *.txt).
  2. Transfer it to the /dev_hdd0/game/NP00PKGI3/USRDIR/ folder on your PS3 (via FTP or USB).
  3. Launch PKGi and press Refresh to load the game list.
  4. Browse the list, select a game and start the download: PKGi will install the .pkg automatically.
💡

Tip: PKGi can also load multiple databases: pkgi_games.txt, pkgi_dlcs.txt, pkgi_themes.txt, etc. The format is a simple CSV: contentid,flags,name,description,rap,url,size,checksum.

Advanced usage: custom store configuration

You can point PKGi to any remote database by editing the config.txt file:

url http://www.mysite.com/mylist.csv
url_demos http://www.mysite.com/demos.csv

PKGi will download and synchronize these lists on the next Refresh.

Troubleshooting

Common Errors

IssueLikely CauseSolution
80029513 — Invalid copyright information Corrupted or improperly signed PKG. Reinstall the PKG. Verify it is complete. On HEN, ensure HEN is enabled.
80010006 — Game won't launch Missing PS2 Classics Placeholder (on HEN). Install the [PS2U10000]_PS2_Classics_Placeholder.pkg.
80028F10 — Display issue 720p resolution conflict. Disable 720p in Settings > Display Settings > Video Output Settings > Custom.
Game freezes or crashes Corrupted ISO or poorly built PKG. Re-download the PKG. Try a different mod version. Check compatibility.
klicensee error / unreadable content Wrong or missing license key. Verify the klicensee matches the game. Re-extract it from the .rap if needed.

Check Firmware Version

To find your firmware: Settings > System Settings > System Information.
