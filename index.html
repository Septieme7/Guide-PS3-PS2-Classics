01

Guide complet : Installer vos jeux PS2 Classics sur PS3 CFW/HEN

Ce tutoriel vous guide pas à pas dans l'installation de jeux PS2 Classics sur une PlayStation 3 modifiée (CFW ou HEN). Que vous utilisiez une clé USB ou le FTP, chaque méthode est détaillée avec les commandes exactes et les chemins à respecter.

ℹ️

Important : Ce guide s'applique aux PS3 sous CFW (Custom Firmware) et HEN (Homebrew Enabler).
Le CFW offre une méthode plus simple (ISO non chiffré dans PS2ISO), tandis que le HEN nécessite une conversion en PKG.

🔄

Mise à jour : Ce guide intègre les méthodes pour les jeux PS2 Classics officiels et les mods (comme les versions Dragon Ball Z). Les liens de téléchargement des mods sont fournis dans la section dédiée.

02

Prérequis essentiels

Avant de commencer, assurez-vous de disposer de :

  • Une PS3 modifiée : CFW (Evilnat, Rebug, etc.) ou PS3HEN activé.
  • Un fichier .pkg de jeu PS2 Classics (ou un ISO PS2 à convertir).
  • Une clé USB formatée en FAT32 (ou NTFS pour les gros fichiers > 4 Go).
  • Un PC avec PS2 Classics GUI (si vous convertissez vos propres ISOs).
  • Le PS2 Classics Placeholder installé (pour le HEN).
⚠️

Rappel HEN : Sur PS3HEN, vous devez activer HEN avant chaque session. Sans cela, les jeux PS2 Classics ne se lanceront pas.

03

Méthode 1 : Installation via clé USB (simple)

C'est la méthode la plus directe. Elle consiste à placer le fichier .pkg sur une clé USB, puis à l'installer depuis le XMB.

Étape 1 : Préparer la clé USB

  1. Formatez votre clé USB en FAT32 (ou NTFS si le fichier .pkg dépasse 4 Go).
  2. À la racine de la clé, créez un dossier nommé PKG (en majuscules).
  3. Copiez le fichier .pkg dans ce dossier PKG.

Étape 2 : Installer depuis la PS3

  1. Insérez la clé USB dans un port de la PS3.
  2. Sur le XMB, allez dans Jeu > Gestionnaire de paquets > Installer les fichiers PKG.
  3. Sélectionnez Support USB (ou le nom de votre clé).
  4. Naviguez jusqu'au dossier PKG et sélectionnez le fichier .pkg.
  5. Appuyez sur X pour installer.
  6. Une fois l'installation terminée, le jeu apparaît dans la colonne Jeu du XMB.
💡

Astuce : Pour les très gros fichiers, utilisez une clé en NTFS. Le FAT32 est limité à 4 Go par fichier.

04

Méthode 2 : Installation via FTP (avancée)

Idéale pour les gros fichiers ou si vous ne voulez pas manipuler de clé USB. Vous transférez le PKG directement dans le disque dur de la PS3.

Étape 1 : Configurer le serveur FTP sur la PS3

  1. Assurez-vous que webMAN MOD ou multiMAN est lancé (il active le serveur FTP).
  2. Notez l'adresse IP de votre PS3 (visible dans Paramètres > Paramètres réseau > Informations de connexion).

Étape 2 : Transférer le fichier avec FileZilla

  1. Ouvrez FileZilla sur votre PC.
  2. Dans les champs en haut, entrez :
    • Hôte : 192.168.1.70 (l'IP de votre PS3)
    • Nom d'utilisateur : root
    • Mot de passe : (vide par défaut)
    • Port : 21
  3. Cliquez sur Connexion rapide.
  4. Dans le volet de droite (PS3), naviguez jusqu'au dossier /dev_hdd0/packages/.
  5. Dans le volet de gauche (votre PC), localisez votre fichier .pkg.
  6. Glissez-déposez le fichier dans le dossier packages.
  7. Attendez la fin du transfert.
⚠️

Important : Vérifiez que le mode de transfert est bien en Binaire (menu Transfert > Type de transfert > Binaire). Un transfert ASCII corromprait le fichier.

Étape 3 : Installer depuis le XMB

  1. Sur la PS3, allez dans Jeu > Gestionnaire de paquets > Installer les fichiers PKG.
  2. Sélectionnez Stockage système (le disque dur interne).
  3. Le fichier .pkg apparaît dans la liste. Sélectionnez-le et appuyez sur X.
  4. Confirmez l'installation et attendez la fin.
05

Lancement via webMAN MOD (recommandé)

webMAN MOD est l'outil idéal pour gérer et lancer vos jeux PS2 Classics. Il offre un accès rapide à la bibliothèque de jeux et permet de monter les ISOs.

Installer webMAN MOD

  1. Téléchargez le dernier webMAN_MOD_[version]_Installer.pkg depuis la page des releases GitHub.
  2. Installez-le via la méthode USB ou FTP expliquée ci-dessus.
  3. Après installation, lancez l'icône webMAN MOD depuis le XMB.

Lancer un jeu PS2 Classics

  1. Ouvrez webMAN MOD (via le XMB ou l'interface web).
  2. Naviguez jusqu'à la section Games > PlayStation 2 (ou PS2 Classics).
  3. Sélectionnez votre jeu dans la liste. webMAN le montera automatiquement.
  4. Le jeu se lancera comme un jeu PS3 normal.
ℹ️

Accès web : Vous pouvez aussi gérer votre PS3 depuis un navigateur PC en tapant http://[IP-PS3]/.

  3. Le mod apparaîtra dans le XMB sous son nom (ex: "CANON v4" ou "SUPER MAX v7").
07

Licences klicensee — Comprendre et obtenir les clés

Les jeux PS2 Classics ne sont pas de simples ISO : ce sont des PKG chiffrés qui nécessitent une clé de licence numérique appelée klicensee pour être déverrouillés. Sans cette clé, la PS3 refusera de lancer le jeu.

🔑 Qu'est-ce que la klicensee ?

La klicensee est une clé de licence unique qui permet de déchiffrer le contenu d'un jeu PS2 Classics. Il faut distinguer deux cas bien différents :

Type de jeuSourceklicensee
Jeux officiels du PSN Achetés sur le PlayStation Store (ou obtenus via NoPayStation) Unique à chaque jeu — stockée dans le fichier ISO.BIN.EDAT du PKG
Jeux créés par la communauté Convertis par vous-même (PS2 Classics GUI) ou par des moddeurs Générique et universelle pour tous les jeux (voir ci-dessous)
🔑

Clé générique universelle (pour les jeux créés par la communauté) :

E4E54FD67C16C316F47829A30484D843

Cette clé est utilisée par défaut dans PS2 Classics GUI et par la plupart des mods. Elle fonctionne sur toutes les PS3 CFW/HEN.

ℹ️

Structure d'un PKG PS2 Classics officiel :

  • ISO.BIN.EDAT — l'ISO du jeu PS2 chiffrée avec la klicensee.
  • PARAM.SFO — les métadonnées (titre, ID, catégorie).
  • ICON0.PNG — l'icône du jeu dans le XMB.
  • Le Placeholder (séparé) : [PS2U10000]_PS2_Classics_Placeholder.pkg.

La klicensee sert à déchiffrer l'ISO.BIN.EDAT au moment du lancement. C'est pourquoi chaque jeu officiel a sa propre clé.

Les jeux PS2 Classics officiels sont distribués sous forme de PKG chiffrés. Voici les sources les plus fiables utilisées par la communauté :

🛠️ Comment obtenir la klicensee d'un jeu officiel ?

Trois méthodes principales existent, selon ce que vous avez sous la main :

Méthode 1 : Extraction depuis le PKG avec PS2 Classics GUI

C'est la méthode la plus simple si vous avez déjà le PKG officiel.

  1. Téléchargez et lancez PS2 Classics GUI sur votre PC.
  2. Ouvrez l'onglet « Decrypt ».
  3. Sélectionnez votre fichier .pkg officiel.
  4. Renseignez la klicensee (si vous l'avez déjà) ou cliquez sur « Get klicensee from RAP » si vous disposez du fichier .rap associé.
  5. Lancez le déchiffrement : le logiciel extrait l'ISO PS2 déchiffré dans le dossier de votre choix.

Méthode 2 : Extraction depuis un fichier RAP

Si vous avez le .rap (fichier de licence Sony) mais pas la klicensee, utilisez un convertisseur.

  1. Récupérez le fichier .rap correspondant au jeu (fourni avec le PKG sur NoPayStation).
  2. Téléchargez l'outil rap2klicensee.exe (disponible sur PSX-Place ou dans la toolbox d'Aldostools).
  3. Placez le .rap dans le même dossier que l'outil.
  4. Lancez la commande : 
    rap2klicensee.exe mon_jeu.rap
  5. L'outil affiche la klicensee correspondante (32 caractères hexadécimaux).

Méthode 3 : Base de données klicensee communautaire

La communauté maintient des listes publiques de klicensee pour les jeux PS2 Classics les plus courants.

  • PSX-Place : section « PS3 PS2 Classics » du forum — de nombreux topics partagent des listes de klicensee.
  • GitHub : recherchez ps2-classics-klicensee ou klicensee-database — plusieurs dépôts maintiennent des fichiers .txt avec les clés.
  • Discord de la scène PS3 : les serveurs comme « PS3 Homebrew » ou « PS3 Scene » ont des salons dédiés où les clés circulent.
⚠️

Important : La klicensee est propre à chaque jeu officiel. Ne réutilisez jamais une klicensee d'un autre jeu — la PS3 refuserait de lancer le PKG.

08

PKGi Store — Télécharger des PKG directement sur la PS3

PKGi PS3 est un homebrew qui permet de télécharger et installer des fichiers .pkg directement sur votre PS3, sans passer par un PC. C'est l'outil idéal pour récupérer des jeux PS2 Classics depuis des dépôts communautaires comme NoPayStation ou des configurations personnalisées.

ℹ️

PKGi ne gère que les fichiers .pkg. Il ne télécharge pas les ISOs PS2 bruts. Pour ces derniers, utilisez webMAN MOD (ISO dans /dev_hdd0/PS2ISO/) ou convertissez-les avec PS2 Classics GUI.

Installer PKGi

  1. Téléchargez le dernier pkgi-ps3.pkg depuis la page des releases GitHub.
  2. Installez-le via la méthode USB ou FTP expliquée ci-dessus.
  3. Lancez l'icône PKGi depuis le XMB (colonne Réseau).

Configurer PKGi avec NoPayStation

Pour télécharger des jeux depuis NoPayStation, vous devez fournir à PKGi un fichier pkgi.txt contenant la liste des jeux.

  1. Récupérez le fichier pkgi.txt fourni par NoPayStation (ou téléchargez-le ICI : https://github.com/Septieme7/PS3-PKGI-1.30 avec les fichiers *.txt).
  2. Transférez-le dans le dossier /dev_hdd0/game/NP00PKGI3/USRDIR/ de votre PS3 (via FTP ou USB).
  3. Lancez PKGi et appuyez sur Refresh pour charger la liste des jeux.
  4. Naviguez dans la liste, sélectionnez un jeu et lancez le téléchargement : PKGi installera automatiquement le .pkg.
💡

Astuce : PKGi peut aussi charger plusieurs bases de données : pkgi_games.txt, pkgi_dlcs.txt, pkgi_themes.txt, etc. Le format est un simple CSV : contentid,flags,name,description,rap,url,size,checksum.

Utilisation avancée : configuration d'un store personnalisé

Vous pouvez pointer PKGi vers n'importe quelle base de données distante en éditant le fichier config.txt :

url http://www.monsite.com/maliste.csv
url_demos http://www.monsite.com/demos.csv

PKGi téléchargera et synchronisera automatiquement ces listes au prochain Refresh.

Dépannage

Erreurs courantes

ProblèmeCause probableSolution
80029513 — Informations de copyright invalides PKG corrompu ou mal signé. Réinstallez le PKG. Vérifiez qu'il est complet. Sur HEN, assurez-vous que HEN est activé.
80010006 — Le jeu ne se lance pas Placeholder PS2 Classics manquant (sur HEN). Installez le [PS2U10000]_PS2_Classics_Placeholder.pkg.
80028F10 — Problème d'affichage Conflit de résolution 720p. Désactivez 720p dans Paramètres > Affichage > Sortie vidéo > Personnalisé.
Le jeu freeze ou plante ISO corrompu ou PKG mal construit. Re-téléchargez le PKG. Essayez une autre version du mod. Vérifiez la compatibilité.
Erreur klicensee / contenu illisible Clé de licence incorrecte ou manquante. Vérifiez que la klicensee correspond bien au jeu. Réextrayez-la depuis le .rap si nécessaire.

Vérifier la version de firmware

Pour connaître votre firmware : Paramètres > Paramètres système > Informations système.
